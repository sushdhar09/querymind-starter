## Known ambiguities

- **Revenue.** `orders.total_amount` is the value of the order at checkout; `payments.amount` is what the payment gateway actually captured and can differ because of refunds. Both list "revenue" as a synonym, so a question that only says "revenue" is ambiguous. The linker reports the ambiguity and the chat UI asks which one is meant; naming a table ("revenue from payments") resolves it.
- **Status.** `orders.status` and `payments.status` use different value sets (see above); mention the table or one of its values.
- **Name.** `customers.name` and `products.name` share a column name; mention customers or products.
